# 所沢キャンパス祭 2026 公式HP

早稲田大学 所沢キャンパス祭（通称：とこ祭）2026の公式ホームページです。
本リポジトリは、HTML/CSS/JavaScriptを用いた静的サイト構成で、Vercel等のプラットフォームでの公開を前提に管理されています。

---

## 🚀 公開ページ紹介

### 1. トップページ (`index.html`)
サイトのメインエントランスです。

### 2. 新歓特設ページ (`shinkan.html`)
新入生に向けた情報を集約したページです。

### 3. 企画一覧ページ (`kikaku.html`)
吉川愛、重松清、十文字幻斎、ステージ企画、教室内企画、屋台企画へのバナーを掲載しています。
スマホ（600px未満）では1列、タブレットでは2列で表示します。PC（1200px以上・マウス操作が可能）では、とこみどりを中心に6つのバナーが風車のように回ります。「一覧で見る」で3列表示にも切り替えられます。デザインは `kikaku.css` で調整できます。
`kikaku.js` で風車の回転、見出し・バナーの登場、一覧表示のマウス位置に応じた傾き、タップ時の動きを付けています。風車は1周120秒で、ホバー・キーボードフォーカス時は停止し、選んだバナーが正面を向きます。端末の「視差効果を減らす」設定にも対応しています。
未公開の企画は `coming.html` に接続しています。公開時は各バナーの `href` と「詳細は準備中」の表示を更新してください。

### 4. 準備中ページ (`coming.html`)
現在制作中のコンテンツを表示する待機ページです。

### 5. 屋台企画ページ (`yatai.html`)
祭カラーのピンク・オレンジ・水色・紫で、提灯と屋台のひさしを演出したページです。
768px以上は3列で、最終行の余り1〜2件は中央揃えにします。767px以下は幅320pxまでのコンパクトな1列で屋台を表示します。企画一覧の「屋台企画」から移動できます。

福引企画とグロース就活DXPOは101号館側に掲載しています。

屋台情報は `yatai.html` に静的に掲載し、JavaScript無効時も画像・屋台名・団体名・場所・時間・受付方法を表示します。
100号館側21件・101号館側10件の計31件で、添付一覧のエリア内の順序に従っています。一覧で時間が空欄の5件は時間の行を表示していません。
キャッチコピーは「2026所祭パンフレット・HP掲載内容（回答）」の「パンフ情報」シートI列から、30企画に掲載しています。「無し」のエナジードリンク配布は表示を省略し、編集者向けメモは公開文に含めません。
全31企画に個別画像を掲載しています。基礎ゼミ19は「スモアサンド」に変更し、提供された商品画像を掲載しています。商品説明は2026年10月20日の提供内容に合わせて更新しています。100号館側には100号館スロープで行うライブ企画2件も含みます。

元画像と一覧用の軽量WebP画像は、どちらも `images/yatai/` 直下に保存します。WebP専用の別フォルダは作成しません。画像は切り抜かず枠内に収め、遅延読み込みします。屋台画像はクリックによる遷移・拡大を行いません。
画像の周囲は4色の青海波柄・扇飾り・紙吹雪で装飾しています。スクロール時に上から一度だけ滑らかに降りるアニメーションを加えています。透明度の切り替え・傾き・タップ時の紙吹雪はなく、端末の「視差効果を減らす」設定では動きを止めます。
うなぎには目立つ「うなぎを注文する」ボタン、ずるずるらくだにはX、LSにはInstagramへのリンクを掲載しています。外部リンクは新しいタブで開きます。
画像を差し替える際は該当カードのリンク先、画像パス、代替テキスト、幅・高さを更新してください。` katsuragawa.png` は先頭に半角スペースがあるため、リンクでは `%20katsuragawa.png` と指定しています。

屋台一覧の上に、`images/yatai/100.png`（100号館側）と `101.png`（101号館側）のマップを掲載しています。
マップの差し替えは `yatai.html` の各リンク・画像パス・画像サイズを更新してください。同名ファイルのキャッシュ更新用に、リンクと画像の `?v=` も新しい値に揃えます。画像は縦横比を保って全体を表示します。
マップはクリック・タップでページ内に拡大表示し、「＋」「−」で最大16倍まで拡大・縮小できます。拡大後は縦横スクロールで移動し、「全体表示」で戻します。閉じるボタン・Escapeキー・背景クリックで閉じられます。
JavaScript無効時もマップを表示し、クリックで元画像を別タブに開けます。個別の屋台画像にはリンクを設定していません。
画像の読み込み失敗時は、JavaScriptで屋台情報を残したまま画像欄を準備中に戻します。

### 6. 教室内企画ページ (`kyoshitsu.html`)
100号館の1〜4階、101号館1階ラウンジ、キャンパス各所で開催する21企画を掲載しています。キャンパスツアー・バラエティゲーム・健康スタンプラリー＆スポーツフェスタは「キャンパス各所」にまとめています。紙ヒコーキ＆スライム（理工展連絡会）は2階・3階の両方に掲載しています。キャンパスツアーには並木道の写真（原本：`images/kyoshitsu/campastour.jpg`）を使用しています。角川講演会は重松清アンコール特別授業に統合し、事前予約あり（無料）として掲載しています。
768px以上は3列・余りは中央揃え、767px以下は幅288pxまでの1列です。本文の最大幅は1000pxにし、カード・文字・余白をコンパクトに調整しています。PC・スマホとも企画名・団体名・紹介文・場所・時間・予約を中央揃えにしています。長い企画名は言葉のまとまりで改行し、クイズの8つの開催時刻は2列で表示します。共通の4色に、100号館をイメージした白い建築・窓枠・コンクリートの目地を合わせています。
企画情報はHTMLに保持し、フロアへのリンクと一覧はJavaScriptなしでも利用できます。`kyoshitsu.js` はメニュー開閉・画像読み込み失敗時の表示を担当します。ポスターは `images/kyoshitsu/*-poster.webp` を切り抜かずに表示します。重松清・十文字幻斎には縦長のポスターを使用しています。画像の余白は4色の窓枠・配管・図面で装飾し、スマホの見出しは薄い校舎イラストの上に中央揃えで重ねています。フッターにも本文の背景と4色のラインが続きます。
